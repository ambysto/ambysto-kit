## Architecture

```
Sources/
  AmbystoLicense/            (0.1, unchanged)
  AmbystoProcess/            reads processes; never signals, never deletes
    ProcessReader.swift      pid list, bsd info (uid, ppid, start time, name), path, cwd, argv, rusage,
                             open files, listening TCP sockets, mapped files — each `nil` when unreadable
    ProcessIdentity.swift    (pid, start time); `current(of:)`; equality = same process
    MachClock.swift          ticks → ns (Optimer)
    ProcessSampler.swift     CPU % (per core) and footprint from rusage deltas keyed by identity (Optimer, minus grouping)
  AmbystoSafety/             file-safety gate; never deletes
    FileIdentity.swift       FileIdentity, FileStamp (Space)
    PathCanonicalizer.swift  firmlinks, realpath, visible paths (Space)
    NeverTouch.swift         the suite-wide list + RealPath (Space)
    SafetyGate.swift         Space's SafetyPolicy, generalised: protection checks in the Kit, allowed roots from the app
    InUseChecker.swift       processes, open files, mapped-file snapshot (Space), built on AmbystoProcess
    FullDiskAccess.swift     (Space)
Tests/
  AmbystoProcessTests/, AmbystoSafetyTests/   (ported + new)
docs/spec/process.md, docs/spec/safety.md
scripts/compare-sockets.sh, scripts/compare-cpu.sh
```

`AmbystoSafety` depends on `AmbystoProcess` (for the in-use check). Neither depends on `AmbystoLicense`.

### The one API change: allowed roots come from the app

Space's `SafetyPolicy.check(url, root: AllowedRoot, expected:)` hard-codes Space's three roots. In the Kit:

```
public protocol AllowedRootRule: Sendable {
    /// nil = the canonical real path is inside this rule's roots; otherwise a plain refusal reason.
    func refusal(realPath: String, isDirectory: Bool, context: SafetyContext) -> String?
}
public struct SafetyGate {
    init(home: URL, systemRoots: [String] = NeverTouch.defaultSystemRoots, canonicalizer: PathCanonicalizer = .shared)
    func check(_ url: URL, rule: some AllowedRootRule, expected: FileStamp?) -> SafetyDecision
    func restoreDestinationRefusal(_ path: String, rule: some AllowedRootRule) -> String?
}
```

Order inside `check` is unchanged from Space: exists → not a symlink → canonical path → unchanged since the scan → same volume → not `/` or home → **protection checks (Kit)** → **allowed-root rule (app)**. Space's `homeItem`, `applicationBundle` and `leftover` become three rule values inside Space when it migrates; the Kit ships a `HomeItemRule` example used by the tests (Space's `homeItem` behaviour), not as a product rule.

## Files (in build order)

Branch `aps-11-kit-safety-core` → PR → `main`; one commit per group; Co-Authored-By trailer.

### 1. Specs — `docs/spec/process.md`, `docs/spec/safety.md`
- `process.md`: what a process record holds; "unreadable" instead of failure; identity = (pid, start time); CPU % per core from usage deltas between two samples of the same identity (first sample has none); listening sockets (TCP LISTEN, address and port, one record per socket); Windows notes (process snapshot, `GetExtendedTcpTable`, `GetProcessTimes`).
- `safety.md`: the never-touch list (Space's, item by item, macOS paths + Windows equivalents), the gate's checks and their order, "contains a protected item" rules, identity on every ancestor, the in-use rules (executable, working directory, arguments incl. relative ones, open files, mapped files snapshot every 10 s), the allowed-roots split (what an app must supply), and the restore-destination rules.

### 2. Package — `Package.swift`
Add library products `AmbystoProcess` and `AmbystoSafety`, their targets and test targets. No dependency changes.

### 3. `AmbystoProcess`
- Merge the two `ProcessReader`s: Space's (open files, mapped files, argv, cwd) + Optimer's rusage reader + new `listeningSockets(_ pid:) -> [ListeningSocket]` (`port`, `family`, raw local address bytes; TCP LISTEN only).
- `ProcessIdentity` replaces Optimer's `ProcessKey`.
- `ProcessSampler` from Optimer without `AppGrouper` identity: returns `[ProcessUsage]` (identity, ppid, name, path, footprint, CPU %, disk B/s) and a hidden count; app grouping stays in Optimer.
- Tests: MachClock (Optimer's three); `parseProcArgs`; this process is found with the right path and cwd; a spawned `/usr/bin/nc -l 127.0.0.1 <port>` shows up in `listeningSockets` with that port; a spawned busy loop shows CPU > 50% after two samples; identity changes when a pid is reused (simulated by a different start time); unreadable pids return `nil`, not errors.

### 4. `AmbystoSafety`
- Port Space's files; `SafetyPolicy` → `SafetyGate` + `AllowedRootRule` (above); `InUseChecker` uses `AmbystoProcess`.
- Port **all** of Space's safety tests, rewritten against `SafetyGate` with the test `HomeItemRule` (and small test rules for app bundles and leftovers, so every refusal path is still covered): every never-touch entry under every rule, Apple app data, firmlinked spelling of `~/Library/Keychains` on this Mac, identity on ancestors, changed/replaced files, 1970 dates, restricted items, symlinks, protected data inside a folder, restore destinations; the in-use tests with real `tail -f`, cwd and `mmap`.
- New: a rule cannot widen the protection (a rule that allows everything still cannot reach a never-touch item).

### 5. Proof scripts — `scripts/`
- `compare-sockets.sh`: a tiny `swift run` of a debug-only executable `ambysto-process-probe` (test target helper, not a product) prints the user's listening ports; compared with `lsof -nP -iTCP -sTCP:LISTEN` (criterion 2).
- `compare-cpu.sh`: the probe samples twice 2 s apart; compared with `top -l 2 -s 2 -stats pid,cpu` for the top 10 processes (criterion 3; within 5 percentage points).

## Risks

| Risk | Catch |
|---|---|
| Generalising `SafetyPolicy` loses a check | The gate keeps Space's order; every Space test is ported; the "rule cannot widen protection" test. |
| Two `ProcessReader`s merged with a subtle difference (buffer sizes, EPERM handling) | Union of both test sets; unreadable → `nil` tests. |
| CPU % wrong by the tick factor or after pid reuse | MachClock tests; identity-keyed deltas; reuse test. |
| Listening sockets miss IPv6 or report ports in host order | Test with an IPv4 and an IPv6 listener; `lsof` comparison. |
| Flaky tests with spawned processes | Short-lived helpers with explicit waits, serialized suites (as in Space). |
| The libraries gain deletion or signals later | Proof grep on `Sources/AmbystoProcess` and `Sources/AmbystoSafety`: no `trashItem`, `removeItem`, `kill(`, `killpg`, `Process(`, `posix_spawn`. |
| Kit has no tag yet | DevBox pins a commit; tags follow the license release. |

## Proof

1. `swift build -c release`: 0 warnings (whole Kit).
2. `swift test`: all pass, including every ported Space safety test and Optimer monitor test, and the new socket, sampler and rule tests (criterion 1).
3. `scripts/compare-sockets.sh` equal to `lsof` (criterion 2).
4. `scripts/compare-cpu.sh` within 5 points for the top 10 (criterion 3).
5. Grep: no deletion, signal or process-spawning calls in the two libraries (criterion 5).
6. Specs: no Swift types outside macOS notes (criterion 6).
7. DevBox groups 3–7 build on a pinned Kit commit with no process-reading code (criterion 4; checked when DevBox reaches those groups).
8. Independent review against the intent and this plan.
